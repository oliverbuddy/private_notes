1. **弹输入法内容被顶起**：根因不是 `resizeToAvoidBottomInset`，而是**工具条挂在 Column 里**，
   键盘一弹就把列表视口挤矮一截；再叠加 `_ensureVisible(alignment: 0.62)` 和固定

   修法三条：
   - 工具条改 `Positioned(bottom: keyboardInset)` 浮层，不参与布局；标签栏高度恒定 →
     键盘出现时内容区高度完全不变；

   - `_ensureVisible` 改成「只在块真的被挡住时滚最小距离」，不再强行拉到视口 62%。
   实测：点第二段文字，第一行与图片一像素没动。

2. **主页标签弹层加删除**：chip 右侧加 ×，二次确认「删除标签 #x？会从 N 条小记里移除」，
   `NoteRepository.deleteTag()` 只摘 tags、不刷新 updated（整理标签不该把笔记顶到最前），
   删掉的标签同时清掉 activeTag。弹层内容包 `ListenableBuilder`，删完原地刷新。

3. **双击放大被裁**：两个根因——① `InteractiveViewer` 套在 `Center` 里、child 是 `Image`
   （尺寸=图片自身），视口就只有图片那么大，放大后被这块小视口裁掉；②
   `SingleTickerProviderStateMixin` 撑两个 AnimationController，**第一次双击直接断言崩溃**
   （debug 包必现，之前没人测过双击）。修：视口铺满整屏 + `TickerProviderStateMixin`
   + 缩放边界按「图片 contain 后的矩形」算（解析图片尺寸，含 letterbox）。新增 widget 测试
   双击后 scale≈2.5 且视口=整屏。

   修：`_handleTextChange` 首行 `if (text == entry.lastText) return;`。

## 第二十四轮：编辑页深挖（焦点丢失 / 撤销重做 / 输入即转换 / 组词样式）

用户报「有序列表返回删除数字编号时收起键盘、光标消失」，要求把详情页编辑体验做到超过语雀。

1. **退格删空列表项丢焦点（本轮报告的 bug）**：根因是 `_mergeIntoPrevious` 只把块从
   列表里删掉，没有把 `_focusedEntry` 交给上一块 —— 那一块不再是 TextField，
   `requestFocus` 无处落地，焦点静默消失（键盘收、光标没）。
   修：合并时 `_focusedEntry = target` 并重新 requestFocus。
   **同一类 bug 还有一处**：`_insertImageBlock/_insertFileBlock` 也只 requestFocus
   不同步 `_focusedEntry` → 插完图光标没了。一并修掉。
   **教训：凡是「会改变 _focusedEntry 所指块」的操作（合并、插入、删除、撤销还原），
   必须同时更新 _focusedEntry，否则就是「键盘莫名收起」。**

2. **撤销 / 重做（语雀有，我们之前没有）**：快照栈 `_EditorSnapshot`，
   **存块结构而不是拼接的 markdown**（两个相邻文本块在 markdown 里就是一个换行，
   拼起来再解析会糊成一块 —— 第一次实现踩了这个坑：撤销一次光标跳到上一段）。
   - 打字按 800ms 合并成一步；结构改动（回车拆块/合并/格式命令/插入附件）各占一步，
     且**结构改动之后的下一次打字必须另起一步**（`_coalesceBlocked`），否则撤销会连
     回车一起退掉。
   - 撤销落到「还没点进来」的那一帧时不踢回浏览态，留在当前块。
   - 按钮放在底栏右侧（撤销/重做/收键盘），无历史时置灰但占位（避免工具栏抖动）。
   - 外接键盘 ⌘/Ctrl+Z、⇧+Z。

3. **输入即转换**：`[] `/`[x] `/`* `/`+ ` 归一化成 `- [ ] `/`- [x] `/`- `。
   **必须走 `TextInputFormatter`**，不能在监听器里改写 controller —— 组词期间改写会被
   IME 的下一次提交覆盖（真机实测 `[] ` 变成 `- []`，中间空格丢了）。

4. **组词期间样式不生效**：原来 `buildTextSpan` 在 composing 时整段交回默认实现，
   英文单词打到一半整个标题会跳回正文字号。改成自己给组词区叠下划线
   （`_withComposingUnderline`），样式照常生效。

5. **空列表项回车退出列表会多一个空行**：现在只去掉本块记号、不再插新块。

6. 其它：代码围栏（```）内回车改成本块内软换行，不再把围栏劈成两半；
   粘贴/插图/删块/格式命令都接入撤销。

验证：analyze 0、**238/238**；模拟器逐项实测（退格删编号仍可继续输入、撤销/重做按钮、
`[] ` → 待办、有序列表面板应用、Aa 套标题后键盘回来、收键盘→浏览→点正文回编辑、
窄屏 900x2000 工具栏不溢出）；笔记文件字节级核对（`sed 's/ /_/g'` 看空格）。
**注意：`od -c` 看空格会和数据列混淆，容易误判「空格丢了」——用 sed 替换空格最可靠。**
release 51.9MB 已装真机。

## 第二十五轮：滚动跳顶根修 + 顶栏改版 + 编辑卡顿优化 + 语雀工具栏调研

1. **「删一行跳到顶部」的真正根因（SCROLL 探针日志抓到）**：`_ensureVisible` 用
   **整块矩形**判断可见性，而磁盘笔记通常只有一个大 TextBlock（比视口还高），
   块顶永远在视口上方 → 每次请求焦点都把页面滚到块的开头。修：改为**光标矩形**
   （RenderEditable.getLocalRectForCaret 转全局），光标可见就一点不滚；
   拿不到光标矩形时只在**整块完全不可见**时兜底。回归测试 editor_scroll_test.dart。
   **方法论：UI 对齐/滚动问题先加临时日志在真机/模拟器抓数据，别靠几何模型推。**

## 第二十六轮：键盘滚动根修（Scaffold 避让）+ 图标/面板/搜索栏 + 工具栏调研方案

1. **「弹输入法内容页上滚」的真正根因**：键盘是浮层（body 不避让）时，
   EditableText 的 scrollPadding 语义是「光标距**视口**底 ≥ padding」——
   视口全高，padding 被迫写成键盘+工具条高度 → 光标距视口底动辄小于它 →
   每次聚焦都被系统推到接近视口顶。**根修：恢复 resizeToAvoidBottomInset: true**
   （视口真正缩短，scrollPadding 恒定 12 语义恢复正确）；连带：
   - 工具条浮层 bottom 从 keyboardInset 改 **0**（Stack 底边已是键盘上沿）；
   - ListView bottomInset 改为工具条高+16（补偿浮层遮挡）；
   - 标签栏随 body 底边上移、被 52 高的工具条整个盖住（视觉无冲突）。
   `_ensureVisible`（光标级判断）保留作兜底。
2. **测试假象教训**：tester 物理窗口 800x600 与 MediaQuery(400x800) 不一致时，
   resize 避让按真实窗口算 → 小屏假象让浮层盖住顶栏、tap 全 miss（3 条撤销测试
   假失败）。修：`tester.view.physicalSize = Size(800,1600); dpr=2` 与逻辑尺寸对齐。
   **Resize/Inset 类改动必须先对齐测试视口再下结论。**
3. 撤销/重做图标 Icons.undo/redo（折角）→ **rotate_left/right（弧形）**，主流样式。
4. Aa 面板块级样式改**横排**：正文/H1/H2/H3 各按真实字号渲染（_HeadingRow/_HeadingCell），
   面板从 5 行降 2 行；测试 finder 同步（'标题 1'→'H1'）。
5. 主页搜索框 surface2 与 pageAlt 几乎同色（浅色 #F5F3EC vs #F7F5F0）→
   改 page 底 + chipBorder 描边（微信式白胶囊）。
6. **语雀工具栏调研结论**（官方文档+快捷键页+市面编辑器统计）：移动端常用栏
   极简（图片/任务/书签/附件），样式收「更多」，插入靠展开与 Markdown 快捷输入；
   市面高频序：标题>加粗>斜体>列表>链接>图片/行内码>代码块>引用>待办>分隔线。
   差距清单与排布方案已给用户，等拍板（快捷输入补全/代码块按钮/分隔线）。

验证：analyze 0、248/248；模拟器实测（键盘弹出最小滚动、工具栏贴键盘、空隙不穿透、
